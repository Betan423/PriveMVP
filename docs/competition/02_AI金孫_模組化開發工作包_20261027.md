# AI 金孫模組化開發工作包

決賽日期：2026 年 11 月 7 日

用途：配合整合藍圖，把後續開發拆成可獨立分派、可驗收、可回復的工作包。

近期核心範圍：分享照片、可疑訊息提醒、手機狀態救援。先完成這三個情境的 v5 隱私處理、量化評測與實機展示；其餘六類任務只在核心路徑穩定後擴充。

## 每日完成定義

- [ ] 當日輸出有版本、SHA-256、輸入路徑、重跑指令與負責角色
- [ ] 測試報告包含通過、失敗、跳過與原因，不只列成功數
- [ ] 文件只引用已凍結證據；目標值與實際結果分開
- [ ] 晚上 21:00 後只整合通過驗收的變更

## 停止線

出現下列任一情況，立即停止合併並修正：

- 未授權任務仍產生雲端封包
- planner_packet 出現姓名、電話、Android ID、精確位置、照片像素或完整通知清單
- Token 可跨任務穩定連結
- 取消後仍執行或保留映射
- 文件數字找不到固定輸入與輸出證據
- 現場版本與已演練版本不一致
