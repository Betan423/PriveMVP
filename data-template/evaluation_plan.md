# 後續產製與評測計畫

此文件是計畫，不是已跑出的結果。不得將待填項目轉成成果數字。

## 兩層資料與用途

1. 自創原始基準：AI依模板產生的模擬事件，保留虛構user_id与相對秒數，用於受控測試。它不含真人記錄，但也不是從真人分布學得的合成資料。
2. 衍生資料：選定PETs後實際產生。可以先試去除事件/使用者ID、粗化時間、按應用類別彙總通知與使用時長，但彙總與粗化不能自動聲稱差分隱私或k匿名。

如果採差分隱私，另定義鄰接資料、隱私單位（事件或完整使用者）、每人貢獻上限、epsilon/delta、機制、組合預算及隨機性。事件層級保護不能宣稱使用者層級保護。若需正式保證，使用有對應保證與可檢查實作的機制，不由LLM隨意加噪替代。

AI在本模板中的角色是自創基準資料。後續PETs要有獨立的處理/轉換設計，避免「生成一次就聲稱所有隱私工作完成」。另外實作AI合成作為PETs的路線亦可，但必須說明輸入、模型、洩漏風險與驗證，不可只拿虛構樣本的零個資作為真人隱私保證。

## 評測表

| 面向 | 建議檢查 | 目前狀態與解釋 |
|---|---|---|
| 規格品質 | 行解析成功率、Schema通過率、場景約束錯誤數、批次覆蓋 | 驗證器可產生報告；不是隱私攻擊測試 |
| 私人內容邊界 | 額外欄位拒絕、禁用自由文字、來源流程人工審核 | 白名單降低暴露面；不能偵測數字隱寫或保證來源沒有抄襲 |
| 模擬指認風險 | 明確定義攻擊者知識、候選池與成功率；用不同背景知識/時間精度比較 | 尚未實作；結果只對模擬人群成立 |
| 形式化保護 | 所選PETs的實際參數與可驗證保證 | 尚未實作；不得寫epsilon=0或100%匿名 |
| 欄位保真度 | 原始模擬基準與衍生集的計數分布距離、使用時長MAE | 尚未實作；不比較真人與AI資料並宣稱老人保真 |
| 關聯保真度 | 使用時長和通知量的關聯差異、分組統計偏差 | 尚未實作；小樣本需揭露不確定性 |
| 實用性 | 通知負荷分析的误差、排序保留率或獨立測試任務表現 | 尚未實作；情境配額與標籤有循環性，規則分類成功不是獨立任務驗證 |

若將資料用於訓練/測試，必須按使用者分割，不能把同一人事件分散至兩側造成洩漏。固定評測資料與設定，報告多次生成/不同參數的結果，不挑選最好一次充當一般成果。

## AI 使用揭露

依 `generation_record.example.json` 填實際工具、模型、用途、提示詞、附件、生成時間、原始输出保存位置、人工修訂、驗證程式版本与限制。本套件由Codex協作建立；模型確切識別碼如未確認應填「未確認」，不能猜。

可用揭露敘述：

「本專案使用生成式AI協助建立資料規格、提示詞及虛構情境範例。團隊限定輸入為不含真人內容的結構規格，設計情境約束並以程式驗證輸出。AI生成的原始基準為模擬資料；後續PETs與評測結果以實際執行紀錄為準。」

若後續尚未執行生成、PETs或評測，揭露中必須維持未執行狀態，不得把計畫寫成完成。
